## Navigasi keyboard (popup izin)

Terverifikasi di `a11y: mode ngobrol + popup izin`:
- `role="alertdialog"` ada pada kartu popup; `aria-live="assertive"`.
- Fokus awal otomatis ke kontrol pertama di kartu (useFocusTrap).
- Tab dari elemen terakhir membungkus ke pertama; Shift+Tab sebaliknya
  (focus trap, tidak bocor keluar kartu).
- Esc meminimalkan kartu ke chip "Menunggu izin" (bukan keputusan);
  chip dapat difokus dan dibuka lagi via Enter; izin tetap pending.

## Kontras AA (tema terang + gelap)

Skrip `/tmp/contrast.ts` (pasangan token penting):

- 13/14 pasangan ≥ 4,5 (AA teks) — LULUS.
- 1 "gagal": aksen `#2F6FE0` di atas `#EDF0FB` = 4,13. Verifikasi pemakaian:
  tidak ada TEKS yang memakai warna aksen di atas latar aplikasi —
  aksen hanya dipakai untuk outline fokus, border spinner, dan ikon
  (elemen non-teks, syarat 3:1 per WCAG 1.4.11 → 4,13 LULUS).
- Semua teks (judul, sekunder, badge risiko, bubble, chip status)
  memenuhi AA di kedua tema.
